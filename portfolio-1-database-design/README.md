# Portfolio 1: Database Design and Modelling

**Course:** MIT 8103 — Advanced Database Systems  
**Case study:** EliZeta Group multi-store e-commerce database

## Overview

This portfolio activity designs and implements a relational database for an academic case study of EliZeta Group and its six e-commerce stores.

The database is implemented using PostgreSQL hosted on Supabase. It contains five tables:

- `stores`
- `products`
- `customers`
- `orders`
- `order_items`

## Contents

SQL scripts, the entity-relationship diagram, test outputs, and the database design explanation will be maintained in this folder.

## Implementation and evidence

The database structure and constraints were inspected in Supabase. A validation query was also used to check whether the store identifiers in the existing order items matched the associated orders and products.

The ER diagram and additional evidence will be added as the portfolio progresses.

## Important note

The shared PostgreSQL architecture is an academic design assumption for this case study. It is not a claim about EliZeta Group's actual internal database architecture.

## Data

Fictional sample records are used for demonstration and testing.
