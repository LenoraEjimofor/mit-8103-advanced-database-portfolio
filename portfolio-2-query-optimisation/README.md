# Portfolio 2: Query Processing and Optimisation

**Course:** MIT 8103 — Advanced Database Systems  
**Case Study:** EliZeta Group Multi-Store E-Commerce Database

## Objective

This portfolio examines SQL query processing and optimisation using the EliZeta Group sample database implemented in PostgreSQL through Supabase.

## Planned Activities

1. Write SQL queries that retrieve and summarise data from multiple related tables.
2. Examine query execution plans using PostgreSQL's `EXPLAIN` and, where appropriate, `EXPLAIN ANALYZE`.
3. Investigate the potential benefits of indexing.
4. Compare execution plans and observed performance before and after an optimisation.
5. Document SQL statements, actual results, screenshots, and findings.

## Evidence

SQL scripts, execution-plan outputs, screenshots, and performance observations will be added as the activities are completed.

**Note:** Performance conclusions will be based on observed results. Any limitations caused by the small fictional sample dataset will be documented.
