# Portfolio 3: Transactions and Concurrency

**Course:** MIT 8103 — Advanced Database Systems  
**Case Study:** EliZeta Group Multi-Store E-Commerce Database

## Objective

This portfolio explores transaction management and concurrency control using PostgreSQL through Supabase.

## Planned Activities

1. Demonstrate transaction control using `BEGIN`, `COMMIT`, and `ROLLBACK`.
2. Test how a transaction affects database changes.
3. Examine a concurrency-related issue or control supported by PostgreSQL.
4. Capture actual SQL outputs and document the results.
5. Explain the importance of transaction management and concurrency control for an e-commerce database.

## Evidence

SQL scripts, query outputs, screenshots, and an explanation of the experiments will be added as the activities are completed.

**Safety note:** Experiments will use controlled sample data and will not intentionally alter or delete existing portfolio records.
